无人机注册
接收 UE5 POST /api/drones 请求，持久化无人机信息（名称、型号、IP:Port、视频流地址），自动分配唯一 ID，返回分配的 ID
调用 POST /api/drones，检查返回 ID 唯一且递增；重复名称应返回 4xx 错误

无人机查询
接收 GET /api/drones 请求，返回所有已注册无人机列表，每条记录包含 ID、名称、型号、IP:Port、当前连接状态
注册若干架后调用 GET，验证返回数量和字段完整性

无人机更新
接收 PUT /api/drones/{id} 请求，允许修改除 ID 外的所有字段，持久化更新
修改名称后重新 GET，验证字段已更新

无人机删除
接收 DELETE /api/drones/{id} 请求，从持久化存储中移除，同时清理该无人机的队列和状态
删除后 GET 列表验证已移除；删除不存在 ID 应返回 404

ID↔编号映射
维护无人机 ID 与通讯端口编号（1~6）的映射关系，编号由用户在注册时手动指定，固定对应 UDP 端口；已被占用的编号不可重复分配，注册请求中若编号已占用应返回 4xx 错误；删除无人机时释放对应编号
注册时指定编号 1，再次注册指定编号 1 应返回错误；删除后重新注册编号 1 应成功；调用 /api/debug/drone/{id}/state 验证编号字段与注册时一致

持久化存储
注册数据写入本地文件或数据库，服务重启后数据不丢失
注册后重启服务，GET 列表验证数据仍存在
